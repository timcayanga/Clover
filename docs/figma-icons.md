# Clover icons

Source: [Screens — Organize](https://www.figma.com/design/FNnCmCj90szZAnZ6twMPCy/Screens?node-id=0-1).

- Iconography: section `146:309`, board `33:400`. Original image fills are stored in `assets/3d icons`. The ten refreshed utility illustrations retain their approved simple shapes, turquoise/mint colors and white backgrounds, without Clover logos.
- Category: section `568:26824`. The 23 complete category components are exported as SVG in `web/public/figma-icons/categories`, retaining their category colors and glass surfaces.
- Interface: section `568:26825`. The 13 action/date marks are exported as SVG in `web/public/figma-icons/interface`. `InterfaceIcon` masks these assets with the existing control foreground color. The containing button supplies its accessible name.

`CategoryBrandMark` provides category images throughout the web app. Unknown categories use Uncategorized; Utilities and Investment retain their aliases. Navigation uses the optimized, versioned `navigation/figma-v1` asset directory generated by the existing public asset synchronization script.

The native app uses bundled 96px PNG renders, including category marks in transaction rows and details. Regenerate these after an approved source update from `web/` with `npx tsx scripts/sync-mobile-icons.ts`. Static mappings live in `mobile/src/icon-assets.ts`.

Validation: the shared React category/interface components and navigation images were rendered with application CSS in an isolated browser fixture at desktop and 390px widths. All 49 images loaded; all 13 action masks rendered at 20px, without horizontal overflow at 390px. Native validation uses TypeScript and Expo bundle exports; it does not substitute for installation on an iOS or Android device.
