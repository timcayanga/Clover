SVGs remain the canonical assets. Native PNGs are transparent, tightly cropped vector renders on a 512px square canvas. The navigation icon uses the same approved welcome pose, with transparent margins trimmed so its visible size matches sibling icons. No white background is baked into the artwork.

Use welcome for Ask Clover and initial introductions, guiding for setup/empty collections, thinking for filtered results, and resting for a clear queue. Icons are decorative when their button already has an accessible name.
