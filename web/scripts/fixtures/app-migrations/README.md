# Migration fixture provenance

- `bluecoins-official-advanced.csv`: unmodified public sample published by Bluecoins at https://www.bluecoinsapp.com/csv-templates/Bluecoins_CSV_Advanced_Template.csv.
- `ynab-register-synthetic.csv`: constructed transactions using the English register column profile. Includes a starting balance, memo, flag, split components, refund and both transfer legs. Official export instructions: https://support.ynab.com/en_us/how-to-export-plan-data-Sy_CouWA9. The official help page confirms CSV/TSV transaction export but does not specify all register columns; this fixture is not a downloaded user export or comprehensive version certification.
- `monarch-transactions-synthetic.csv`: constructed transactions using Monarch's documented eight-column CSV profile, with explicit Currency and Hidden extensions to exercise Clover's handling. Documentation: https://help.monarchmoney.com/hc/en-us/articles/4409682789908-Import-data-manually-from-banks-or-other-finance-apps and https://help.monarch.com/hc/en-us/articles/15526600975764-Downloading-Transaction-or-Account-History. Includes original and edited merchant names, tags, refund, transfer and exclusion. It is not an authentic customer export; source files may omit Currency and Hidden.

All names and transactions in the synthetic fixtures are invented. No customer financial data or source-app credentials are needed to run these tests. Exact supported columns and limitations are described in `docs/app-migration-parser-rules.md` at the repository root. New authentic, consented or public export examples can extend these profiles without modifying confirmed data.
